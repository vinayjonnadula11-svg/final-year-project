# CPW-Fed Fractal Antenna for Wireless Applications

## 🎓 Academic Project

This project was carried out as part of my B.Tech Final-Year Project in the Department of Electronics and Communication Engineering (ECE).

As part of my final-year academic work, I worked on the design, simulation, analysis, and fabrication of a CPW-Fed Fractal Antenna for wireless communication applications.

The project provided practical exposure to antenna design, fractal geometry, electromagnetic simulation using ANSYS HFSS, performance optimization, and experimental validation.

Project Type: B.Tech Final-Year Academic Project
Department: Electronics and Communication Engineering
Software Used: ANSYS HFSS
Substrate: RT/Duroid 5870

## 📌 Project Overview

This project focuses on the design, simulation, analysis, and fabrication of a **Co-Planar Waveguide (CPW)-Fed Fractal Antenna** for wireless communication applications.

The proposed antenna uses a fractal geometry on the radiating patch to achieve a compact antenna structure with improved performance characteristics. The antenna is designed and simulated using **ANSYS HFSS**, with an RT/Duroid 5870 substrate having a relative permittivity (εr) of 2.2 and a thickness of 0.787 mm.

The design aims to achieve good impedance matching, low return loss, stable radiation characteristics, and suitable gain for modern wireless communication applications.

## ⚙️ Methodology

The project follows a systematic antenna design and testing process.

**1. Antenna Design**
- Created the initial antenna structure using HFSS.
- Selected RT/Duroid 5870 as the substrate.
- Designed the fractal radiating patch with CPW feeding.

**2. Antenna Optimization**
- Adjusted patch dimensions and fractal slots.
- Optimized feed width and feed gap.
- Evaluated S11, VSWR, and gain to improve antenna performance.

**3. Simulation and Analysis**
- Simulated the antenna using ANSYS HFSS.
- Analyzed reflection coefficient, gain, and VSWR.
- Evaluated antenna performance at the operating frequency.

**4. Antenna Fabrication**
- Fabricated the finalized antenna design using the selected substrate.
- Prepared the physical antenna for practical testing.

**5. Measurement and Validation**
- Measured antenna performance using a Vector Network Analyzer (VNA).
- Compared simulated and measured S11 results.
- Analyzed the variation between simulation and practical measurements.

## 🚀 Conclusion

The CPW-Fed Fractal Antenna was designed, simulated, and fabricated for wireless communication applications.

The proposed antenna demonstrated good impedance matching, low reflection coefficient, and satisfactory radiation performance at approximately 6.33 GHz, with a gain of 4.1 dB and a VSWR of 1.0526.

The comparison between simulated and measured results indicates satisfactory antenna performance and supports the feasibility of the proposed design.
